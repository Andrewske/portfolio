The Jurassic Park metaphor runs throughout: AI is the dinosaurs (powerful but needs containment), the workflow is the park infrastructure, Kevin is both Hammond (building it) and the skeptical scientists (stress-testing it).

**Audience:** Developers interested in AI-assisted coding. Likely skeptical of AI hype, appreciate self-awareness about AI limitations.

**Meta humor opportunity:** The post itself was written using the workflow it describes. AI writing about AI containment. Lean into this.

- Code review as raptor containment protocols
- The model doing something unexpected = dinosaurs breeding
- Context windows as electric fences

- "Your scientists were so preoccupied with whether they could prompt it..."
