# Idea Improvement Brainstorm

Before implementing, review this design through four lenses:

## 1. Simplify
What can be removed or merged? What's the minimum viable version?

## 2. High-Leverage
Small changes with disproportionate value - low complexity, high impact. The 80/20 opportunities.

## 3. Strengthen
What's fragile, unclear, or will cause friction during implementation?

## 4. Stretch (2-3 ideas)
Dream a little:
- **"Wouldn't it be cool if..."** - Fun features that would make someone say "oh that's cool!"
- **Future-proofing** - Ambitious features worth designing hooks for now (cheap to accommodate upfront, expensive to retrofit later)
- **Wild cards** - Ideas that might be genius or terrible

## Response Format

Number ALL suggestions sequentially across sections (1, 2, 3, 4... not restarting per section).

For each suggestion:
- One sentence on **what** changes
- One sentence on **why** it matters
- Complexity: Low / Med / High

End with: **Top 3 recommendations by number, ranked by value-to-effort ratio**

If you'd implement only one thing, which and why?
