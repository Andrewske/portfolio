1. **ON DELETE SET NULL conflicts with NOT NULL constraint**
   - **Problem**: Task 01 defines `playlist_id INTEGER NOT NULL` with `ON DELETE SET NULL`. SQLite cannot set NULL on a NOT NULL column - the delete will fail or behave unexpectedly.
   - **Impact**: Deleting a linked playlist will cause a database error or foreign key violation, breaking the "bucket becomes unlinked when playlist deleted" requirement.
   - **Recommendation**: Change to `ON DELETE CASCADE` - delete the link row entirely when playlist is deleted.
   - **Alternatives**:
     - Option A: `ON DELETE CASCADE` - link row deleted, bucket has no link (cleanest)
